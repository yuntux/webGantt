Aide : Formules de calcul

Les champs calculés utilisent une expression de type SQL (compatibilité GanttProject / H2).

Variables natives disponibles (exclusivement) :

  • uid, id, name, color
  • is_milestone, is_project_task
  • start_date, end_date, earliest_start_date
  • duration, completion, priority, web_link
  • cost, cost_manual_value, is_cost_calculated, notes

Attention : Les champs personnalisés (tpcX) ne sont pas autorisés dans ces formules dans GanttProject.

Exemples d'expressions (syntaxe SQL) :

  • cost * 2 (Double le coût)
  • duration * 8 (Jours en heures)
  • 'Tâche ' || name (Concaténation de texte avec ||)
  • priority = '2' (Test d'égalité avec =)
